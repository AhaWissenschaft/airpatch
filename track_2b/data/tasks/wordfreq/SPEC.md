Read text from standard input and print the three most frequent words.

- A word is a maximal run of the letters `a`-`z`, ignoring case; convert words
  to lowercase. Everything else (digits, punctuation, apostrophes, whitespace)
  separates words.
- Print one word per line as `<word> <count>`, most frequent first.
- Words with the same count are ordered alphabetically.
- If there are fewer than three distinct words, print all of them.
- For input without any word, print nothing.
