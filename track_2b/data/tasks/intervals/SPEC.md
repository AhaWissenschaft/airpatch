Each line of standard input holds an interval `a b` of integers with
`a <= b`. Print the union of all intervals as a sorted list of disjoint
intervals, one per line, in the same `a b` form.

Intervals that overlap or touch are merged: `1 3` and `3 5` become `1 5`.
`1 2` and `3 4` are not merged. Empty input gives no output.
