# Provenance

## Origin

- Started on 2026-10-04 from the official Hack Apertus project template
  (`hackapertus/project-template`, commit 7f23822), imported unchanged as the
  first commit. Everything else was written for this project during the
  hackathon.
- No code, data, task or text from any other project was reused.

No other packages are installed at build or run time.

## Models

- **Apertus v1.5 (8B, 70B)** is the model under evaluation, reached through the
  endpoint in `LLM_BASE_URL`. No other model is part of the solution or of the
  evaluation (no LLM judge: correctness is decided by running tests).

## Tasks and data

- All tasks in `data/tasks` and `data/hidden` were written for this project.
  They are not taken from public benchmarks or online judges. Expected outputs
  are generated by running each task's reference solution (`make expected`).
- Recorded model answers in `data/cassettes/` (if present) are Apertus outputs
  produced by our runs.

## Use of AI assistance during development

The code, tests, documentation and tasks were developed with the help of an
AI coding assistant (Claude Code by Anthropic) working under the direction of
the team. The assistant is not part of the submitted system and is not used at
run time. Every task was checked automatically (`make validate`), and the
pipeline is covered by unit, regression, determinism and isolation tests.
